# Simulateur Smart Grid - Temps Réel & Dashboard Streamlit

Projet professionnel d'aide à la décision pour réseaux électriques, doté d'une acquisition en flux continu et d'une interface web interactive sous **Streamlit**.

##  Exécution

### 1. Mode Terminal (Flux Temps Réel)
```bash
python src/main_temps_reel.py
```

### 2. Mode Dashboard Web (Streamlit)
```bash
 python -m streamlit run src/app_streamlit.py
```
